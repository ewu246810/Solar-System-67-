A BEGINNER'S GUIDE TO WEB DEVELOPMENT

Meet Django,
your Python web toolkit.

Django is a framework: a set of ready-made tools and patterns that helps Python developers build websites. It can take care of common jobs, so you can focus on what your site should do.

01 What it is 02 How it works 03 Key files 04 More facts

THE BIG IDEA

What does Django do?

When someone visits a website, the browser asks the website's computer for a page. Django helps your Python program receive that request, decide what information is needed, and send a response back—often an HTML page.

It is used for the part of a website that runs on the server. Django can work alongside HTML and CSS (which shape the page) and JavaScript (which can add interactions in the browser).

FOLLOW THE REQUEST

How the pieces work together

Imagine a page that shows a list of books.

01 / URLS

Match the address

A URL pattern connects an address, such as /books/, to the Python view that should handle it.

02 / VIEWS

Choose what to do

A view is a Python function (or class) that handles the request. It might ask a model for books, then choose a page to show.

03 / MODELS

Describe saved data

A model describes information, such as a book's title and author. Django can use it to read and save records in a database.

04 / TEMPLATES

Build the HTML

A template is a page layout. Django can put the book information into it and send the finished HTML to the browser.

Easy way to rememberurls.py points to a view; the view can use a model for data and a template for HTML.

IN PLAIN PYTHONviews.py
from django.shortcuts import render

def welcome(request):
    return render(request, "welcome.html")

This small view asks Django to return the welcome.html template as a web response.

EXTRA THINGS TO KNOW

Django facts

FACT 01

It is written in Python

If you know Python, Django lets you use it to build the server side of a website.

FACT 02

It includes useful tools

It comes with features for things like forms, user accounts, and an admin site for managing data.

FACT 03

It works with databases

Django's model tools let Python code work with database records without writing every database command by hand.

FACT 04

It helps with safety

Django includes protections for common web risks. Developers still need to use the tools carefully and follow good security practices.

FACT 05

It is open source

Its source code is public, and people around the world help maintain and improve it.

FACT 06

It has a tiny namesake

Django was named after Django Reinhardt, a well-known jazz guitarist.
