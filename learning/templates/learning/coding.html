TURN IDEAS INTO INSTRUCTIONS

Meet coding,
the language of ideas.

Coding is writing instructions that a computer can follow. People use code to make websites, games, apps, animations, and tools that solve problems.

01 What it is02 How it works03 Web building blocks04 Common questions05 More facts

THE BIG IDEA

What is coding?

A computer can do many things, but it needs instructions. Coding means writing those instructions in a programming language, using rules the computer can understand. The computer follows the instructions to produce a result.

Some code tells a computer to show a message. Other code can respond to a button click, save information, draw a picture, or help run a website. Coders also test their instructions and fix mistakes, called bugs.

Give the computer an instruction

Here is a short example in Python.

PYTHON CODEhello.py

SEQUENCE

Order matters

Instructions usually run in order, from the first step to the next.

CHOICES

Make decisions

A program can check a condition and choose which instructions to follow.

LOOPS

Repeat a task

A loop can repeat instructions, such as drawing each side of a shape.

DEBUGGING

Find and fix bugs

When code does not work as expected, check the instructions and correct the problem.

HOW A WEBSITE COMES TO LIFE

Different tools have different jobs

A website can use several languages and services together.

HTML / STRUCTURE

What is on the page?

HTML marks up content, such as headings, paragraphs, images, and links.

CSS / APPEARANCE

How does it look?

CSS controls colours, fonts, spacing, and how page elements are arranged.

JAVASCRIPT / ACTION

How does it respond?

JavaScript can make a page react to clicks, keyboard input, or new information.

PYTHON / DJANGO

What happens behind it?

Python with Django can handle requests, work with saved data, and prepare pages on a web server.

COMMON QUESTIONS

Web and coding words, explained

Tap a question to see its answer.

What does HTML do?+

HTML gives a web page its structure and content, such as headings, paragraphs, images, and links.

What does CSS do?+

CSS controls how a web page looks, including colours, fonts, spacing, and layout.

What does JavaScript do?+

JavaScript can make a web page interactive, for example by responding when someone clicks a button or by updating content on the page.

What is a database?+

A database stores and organises information so an app or website can save it and find it later, such as account details or game scores.

What is an API?+

An API is a way for different programs to communicate. For example, a weather app can use an API to ask a weather service for forecast information.

What does models.py do?+

In a Django app, models.py describes the data the app works with. Django can use models to save and retrieve that data from a database.

What does views.py do?+

In Django, views.py contains code that handles web requests. A view can get information, decide what to show, and return a response such as a web page.

What does urls.py do?+

In Django, urls.py maps web addresses to views. For example, it can connect /books/ to the view that shows a list of books.

What does manage.py do?+

manage.py is a command-line helper for your Django project. You can use it to start the development server and run Django commands, such as creating and applying database migrations.

What's the difference between project and app urls.py files?+

The project urls.py is the main address book for the whole website. It can send a group of addresses to an app. The app urls.py maps addresses within that app to specific views.

Why do we see __init__.py in many folders?+

__init__.py marks a folder as a Python package, which lets code in it be organised and imported. It is often empty, but it can also contain package setup code.

What does settings.py do?+

settings.py holds configuration for the Django project, such as which apps are enabled and how the database, templates, and security options are set up.

What does the app's migrations folder do?+

It stores instructions for changing the database when your models change. For example, a migration can add a database column for a new model field.

EXTRA THINGS TO KNOW

03

04

You can learn coding by making small projects, experimenting, and improving them one step at a time.
